## Node 6 本地视觉大模型启动与视觉 grounding 修复

### 资料查阅结论

- Qwen3-VL-2B-Instruct 的定位是视觉-语言模型，适合图像理解、目标描述和空间关系判断；本项目用它做实时相机目标可见性验证是合理的，但不能让模型凭记忆直接输出地图坐标。
- VLN/VLM 导航相关工作普遍把语义 grounding 和几何导航分开处理：先从当前视觉观测或多视角观测中确认目标/地标，再映射到地图、拓扑点或导航目标。对本项目来说，对应实现是“实时相机图像 + 目标可见性 JSON + 语义地图坐标”。
- 文献里的主动感知思想对当前问题很关键：当目标不在当前视野中时，应旋转/换视角继续观察，而不是直接用关键词兜底导航。当前 visual scan 的多方向扫描符合这个方向。
- Hugging Face Transformers/bitsandbytes 的 4-bit 量化主要用于降低显存占用。当前 RTX 3060 12GB 同时运行 Isaac Sim 和 Qwen3-VL，使用 4-bit 是合理默认；显存还剩约 5GB 不代表模型没有启动。

### 问题判断

- 原来 `inference_mode=subprocess` 时，Qwen 只会在收到每条指令时临时启动并加载模型，空闲时 `nvidia-smi` 看不到 Qwen 进程，因此容易误判为“本地大模型没有启动”。
- 临时子进程推理还会导致每条任务重复加载模型，启动慢、状态不可观测，并且失败时容易被关键词兜底掩盖。

### 代码修改

- 新增 `src/vln_inference/run_inference_server.py`：
  - 启动后一次性加载 Qwen3-VL。
  - 通过 stdin/stdout JSON-lines 协议提供 `ping`、`predict`、`shutdown`。
  - 常驻 GPU，便于用 `nvidia-smi` 确认模型是否已启动。
- 修改 `qwen_model_wrapper.py`：
  - 增加 `inference_mode=server` / `persistent_subprocess`。
  - 支持启动持久 Qwen worker，并在启动时做 `ping` 健康检查。
  - 推理失败时返回 worker stderr 尾部，便于定位 OOM、bitsandbytes 或 transformers 问题。
- 修改 `vln_node_local.py`：
  - 默认 `inference_mode` 改为 `server`。
  - 新增 `model_startup_timeout_sec`、`inference_request_timeout_sec`、`model_python_executable`。
  - 新增 `allow_inference_fallback`，默认 `false`，避免模型失败后静默走关键词坐标。
  - bridge ready 前必须先确认 Qwen backend ready。
  - 修复初始化 timer 失败后实际不重试的问题。
- 修改 launch 文件：
  - 暴露 `inference_mode`、`allow_inference_fallback`、`model_startup_timeout_sec`、`inference_request_timeout_sec`、`model_python_executable` 参数。

### 结论

- 本地 Qwen 模型已经启动并常驻 GPU；不是“模型没启动”。
- 当前 Qwen 使用 4-bit 量化，显存占用约 `2.3 GB`，所以 12GB 卡上剩余约 5GB 属于正常现象。
- 视觉模型本身能正确返回目标可见性和置信度；前 6 类可见目标的 JSON grounding 是有效的。
- 当前 Node 6 的主要失败来源已经转移到：
  1. Nav2/局部控制执行不稳定，尤其是原地旋转和从 plant/chair 区域再去 chair 的路径。
  2. 仅原地 visual scan 无法看到远处 shelf/purple boxes，缺少“目标不可见时先按语义地图探索到候选区域”的策略。
  3. 语义地图目标词表不够，需要加入 `warehouse rack`、`package area`、`cart with boxes` 等别名。

### 后续建议

1. 保留当前 `server` 模式，继续用常驻 Qwen worker，避免误判模型未启动。
2. 先修 Nav2 局部控制/转向稳定性，再重跑 Trial 6-11。
3. 为语义地图补充别名：
   - `warehouse rack` -> shelf 区域。
   - `package area` -> purple boxes/shelf 区域或单独标注。
   - `cart with boxes` -> cart/boxes 区域。
4. 对于 purple boxes/shelf 类，改成两阶段策略：
   - 如果当前视角不可见，但 instruction/model_target 命中已知语义地图，先导航到候选区域。
   - 到达候选区域后再做 visual scan 确认，而不是在起点原地找远处目标。
